新增「通过 Shizuku 一次性授权」：可以直接在手机内授予独立诊断权限，无需电脑执行命令。

1. 暂时保持所需调试开关开启，通过无线调试启动 Shizuku。
2. 回到推送哨兵，连接并授权 Shizuku，等待辅助进程已连接。
3. 点击「通过 Shizuku 一次性授权」，阅读权限说明并确认。
4. 显示「独立诊断权限已就绪」、读取来源为「应用自身诊断权限」后，可以停止 Shizuku、关闭 USB／无线调试和开发者选项，再核对首页及磁贴。

「允许应用调用 Shizuku」和「给应用自身授予系统诊断权限」是分开的两步；新按钮执行第二步。取消确认不授予权限，只有应用验证实际权限完整后才显示成功。

本次授权涉及 DUMP、PACKAGE_USAGE_STATS 和使用情况 AppOp，可读取系统诊断及应用使用信息。本应用用它们读取 GMS 当前连接。辅助进程验证实际调用 UID、所属用户和固定包名，只能给本应用授权；不接受任意授权对象或命令，不修改 GMS 名单或电池策略。保留手动 ADB 授权／撤销说明，撤销后不会自动重新授权。

验证：[Android 17 完整检查](https://github.com/maixuanfeng1/FCMGuard-HyperOS/actions/runs/43350853363)，两套系统各通过 38 项设备测试，并通过 42 项 Java 单元测试；包含真实 Shizuku 的取消／确认授权、权限生效、服务停止且旧结果过期后的独立读取，以及原有连接状态和磁贴检查。[关闭调试的受控实验](https://github.com/maixuanfeng1/FCMGuard-HyperOS/actions/runs/43347647380) 也验证了普通应用诊断权限在三个调试开关对应设置为 0 时保留。HyperOS 4 的厂商策略仍需手机确认。
