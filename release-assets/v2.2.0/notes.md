修复 Shizuku 无线调试模式下的白名单监听注册路径，并优化 FCM/GCM 应用列表。

- **监听兼容**：Android 17 会拒绝独立 shell 进程注册监听；改由前台守护应用通过标准 ContentResolver 监听，Shizuku 仅负责有权限要求的白名单读写；仍然由变更事件触发处理，没有定时轮询。
- **状态一致**：只有监听注册和初次修复均成功才显示自动保护中；等待连接与失败分别显示。失败时首页显示具体错误，并提供“重试保护”。
- **应用列表**：未开启自启动的应用使用 Material 红色并排在最前面，已开启排在后面；显示 FCM/GCM 应用总数、已开启、未开启、部分开启、无法读取的数量。无法读取不会被当作未开启。从应用设置返回后刷新状态。
- **升级安装**：版本 2.2.0 / versionCode 33，target API 37，沿用 v2.0 / v2.1 的签名，可覆盖安装。没有增加新的库或 JNI 原生库。
