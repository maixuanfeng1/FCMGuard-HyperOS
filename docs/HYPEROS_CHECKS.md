## 检查顺序

| 项目 | 操作 | 应当看到的结果 |
| --- | --- | --- |
| 覆盖升级 | 在已有关注应用和诊断授权的同签名版本上覆盖安装，停止 Shizuku 后冷启动 | 保留关注列表、诊断授权和心跳限频。若旧安装中仍有手动诊断记录或待处理标记，升级后清理。冷启动不弹出授权提示、不启动前台服务、不发常驻通知、不修改系统名单。 |
| 常用入口 | 冷启动打开连接页，在桌面长按 Vigil 图标 | 连接页和桌面快捷方式均可打开 Google 的 FCM 诊断。返回后没有记录弹窗。菜单外观由 HyperOS 桌面决定。 |
| 一次性诊断授权 | 在「设置 → 诊断权限 → 通过 Shizuku 授权」或按 [一次性诊断授权说明](DIRECT_DIAGNOSTIC_ACCESS.md) 通过可信 ADB 授权，关闭无线调试和 Shizuku，重启后再次核对 | 连接页显示应用自身诊断权限来源，能读取时与 Google 诊断一致，磁贴随实际状态变化。HyperOS 拒绝或清除权限时显示未知。 |
| 授权期间展开磁贴 | 预先添加 Vigil 磁贴。发起一次性 Shizuku 授权后，在授权提示出现或辅助进程连接时展开快捷面板，再收起面板并完成授权 | 临时授权流程继续有效。确认授权并完成后，Vigil 释放临时辅助进程。 |
| 诊断权限撤销 | 撤销 DUMP、使用情况权限或拒绝使用情况 AppOp | 旧结果失效，连接状态回到未知。系统名单不应被修改。 |
| 默认免授权 | 未进行诊断授权时直接打开诊断和应用检查 | 这些入口仍可使用，不要求 Shizuku；自动 FCM 状态明确显示未知，不能用网络可达代替已连接。 |
| 取消或中断授权 | 点击「通过 Shizuku 授权」后，在 Shizuku 或应用内权限说明框点击取消 | 不授予 DUMP／使用情况权限，临时辅助进程随之释放，不残留旧授权提示或连接状态。 |
| 已连接对照 | Google 诊断显示 Connected 后，返回连接页并展开快捷面板，等待一次刷新 | 能读取受支持的 GMS 当前状态时，连接页显示「已连接」（英文为 Connected），磁贴点亮。无法读取时保持问号／未知并说明原因。 |
| 断网对照 | 暂时关闭 Wi-Fi 和移动数据，等待 Google 诊断显示未连接，再对照连接页和磁贴 | 网络变化先使旧结果失效。读到明确未连接后显示「已断开」（英文为 Disconnected）、磁贴显示灰色断开图标。无法读取时保持未知。测试会暂时中断联网应用，请在方便时进行。 |
| 恢复联网 | 恢复原来的网络及 VPN 设置，再对照 Google 诊断 | 读到新的已连接状态后才重新点亮。磁贴点击可以尝试发送心跳并进入诊断；不能保证系统接受请求，也不会关闭 GMS。 |
| 撤销后重新授权 | 撤销系统诊断权限并在 Shizuku 撤销 Vigil 后，再次点击「通过 Shizuku 授权」 | 重新向 Shizuku 请求授权并完成临时连接，授权成功后继续释放辅助进程。 |
| 应用设置 | 选择一个通知应用，依次从详情面板打开应用设置、通知设置和电池设置 | 每个入口都对应所选包名，厂商专用入口不可用时退回同一应用的 Android 详情页。 |
| 后台任务锁定 | 在手机管家或最近任务中切换一个关注应用的锁定状态，查看卡片与详情面板，并点击「任务锁定」 | 卡片与详情面板同步更新为已锁定／未锁定（无法读取时显示未知），未锁定不染红也不计入待检查角标；按钮打开手机管家锁定管理页，缺失该入口的 ROM 弹出操作指引。 |
| 应用状态 | 修改一个目标应用的自启动、通知权限或电池策略，再返回 Vigil | 可读取的项目重新检查。系统名单变化在 ROM 提供可读数据及事件时刷新，读取失败显示未知。未开启自启动的应用优先排列并有红色及文字提示，计数与当前列表一致。 |
| 页面状态 | 在应用页切到「查看全部」并向下滚动，再切到设置页切换外观主题 | 当前标签页、列表查看模式和滚动位置恢复；返回系统设置仍会重新读取应用状态。 |
| 进程回收 | 正常使用手机，待系统自行回收 Vigil；之后下拉或点击磁贴 | 可以重新唤起检查。不能运行期间存在检查空档，应用不应假装持续监控；没有常驻通知或定时唤醒。不要用强行停止来模拟普通回收，两者系统语义不同。 |
| 锁屏推送 | 让另一账号向所选应用发送测试通知，分别在 Wi-Fi、移动网络和日常 VPN 下锁屏观察 | 记录应用、网络、发送/收到时间和是否遗漏。检查通知总开关、类别、应用内静音和账号状态。FCM 已连接只能说明 GMS 连接，不能证明每个应用都已注册或保证通知必达。 |

连接状态以受支持的 GMS 当前字段为准，有效期按单调时钟计为 15 秒。网络或授权变化时，旧结果立即失效。连接页和磁贴各自在可见时刷新，读不到新状态时保持未知。

## 失败时需要的信息

提供对应项目、上述版本信息、Google 诊断当时的 Connected/未连接状态、连接页和磁贴的实际状态，以及完整的诊断错误文字即可。截图可先遮挡账号、通知内容和设备标识。

不要把未知状态改成“已连接”来绕过问题。GMS 更新后如果格式不再支持，应先获取当前状态格式的证据，再修改解析器。
